# BestIR — แอปคัดกรอง IR อัตโนมัติ (Standalone, Windows)

## ภาพรวม
แอป desktop สำหรับ "โหลด IR เข้ามา → วิเคราะห์โทนอัตโนมัติ → คัดกรอง/จัดอันดับตามโทนที่ต้องการ → ฟัง A/B ในแอป → ส่งออกไฟล์ที่รอด" เพื่อแทนการเปิด analysis VST วนไปมา เหมาะกับ workflow ที่เริ่มจาก IR ก่อนแล้วค่อยเลือก amp

**Stack:** Python 3.14 (มีในเครื่องแล้ว) + NumPy/SciPy (DSP) + soundfile (อ่าน WAV) + PySide6 (GUI) + pyqtgraph (กราฟ spectrum) + sounddevice (เล่นเสียง) → แพ็กเป็น `BestIR.exe` ด้วย PyInstaller ตอนจบ
*(ถ้า dependency ตัวใดยังไม่มี wheel สำหรับ Python 3.14 จะติดตั้ง Python 3.12 คู่ขนานผ่าน winget แล้ว build บน 3.12 แทน)*

## Core DSP (`app/core/analysis.py`)
อ่าน WAV (mono/stereo, 16–32 bit ทุก sample rate) → หา onset → FFT → smooth แบบ 1/6 octave บนแกน log-frequency → normalize ระดับพลังงาน ให้เทียบ "รูปทรงโทน" กันได้ตรง ๆ ไม่ง้อความดังไฟล์ จากนั้นคำนวณเมตริก:
- **Flatness** (dB เบี่ยงจากแบน ช่วง 80 Hz–8 kHz) — ยิ่งต่ำยิ่ง flat
- **Tilt** (dB/octave 200 Hz–8 kHz) — บวก = bright, ลบ = dark
- **Band levels** 7 ย่าน: Sub/Low/LowMid/Mid/MidHigh/High/Air
- **Peak/Notch** ที่แรงที่สุด (resonance ผิดปกติ), **Effective length** (ms)
- **Auto-tags จากกฎเกณฑ์:** Flat / Bright / Dark / Warm / Scooped / Mid-forward / Boomy / Thin / Fizzy
- Stereo → วิเคราะห์เฉลี่ย L/R และ flag ว่าเป็น stereo

## การคัดกรอง 3 วิธี (`app/core/matching.py` + UI)
ทุกวิธีสร้าง "target curve" เดียวกัน (96 จุด log-spaced) แล้วจัดอันดับด้วยระยะ RMS หน่วย dB:
1. **พรีเซ็ต:** Flat / Bright / Dark / Scooped / Mid-forward / Tight-low / Vintage
2. **สไลเดอร์ 7 ย่าน:** ปรับน้ำหนักแต่ละย่านเป็น dB แล้ว interp เป็น target curve
3. **วาด target curve เอง:** คลิก/ลากจุดบนกราฟ log-frequency

พร้อม **hard filters:** ชื่อไฟล์, sample rate (สำคัญมาก — pack ของคุณมีไฟล์ชื่อเดียวกันซ้ำทั้ง 48k/96k), mono/stereo, ความยาว, tags, เกณฑ์เมตริก (เช่น flatness ≤ 2 dB) — ผลจัดอันดับแสดงเป็นตาราง Top-N โดย curve ที่เข้าใกล้ target ไฮไลต์บนกราฟ

## หน้าจอ (หน้าต่างเดียว, 3 คอลัมน์)
- **ซ้าย — Library:** เพิ่มโฟลเดอร์ (สแกน recursive + progress แบบ background thread) ตารางไฟล์เรียง/sort ได้ทุกคอลัมน์ + แถบ filter ค้นหา/tag
- **กลาง — Plot:** เส้น spectrum ซ้อนกันของ IR ที่ผ่าน filter (จางๆ) + ตัวที่เลือก (เด่น) + target curve (เส้นประ) — hover ดูชื่อ, log-x dB-y
- **ขวา — Inspector:** ตัวเลขเมตริกเต็ม, tags, waveform เล็ก และแผง **Audition**

## Audition ในแอป (`app/core/audition.py`)
- เลือกได้ทั้ง **ไฟล์ riff ของคุณเอง** (WAV) หรือ **สัญญาณทดสอบในตัว** (pink noise / DI power chord สังเคราะห์)
- Convolve ด้วย `scipy.signal.fftconvolve` แล้วเล่นผ่าน sounddevice — สลับ IR ปุ่มเดียว **A/B เทียบเร็ว ๆ**
- **Level-match (RMS normalize) เปิด/ปิดได้** — กันหูถูกหลอกว่า "ตัวดังกว่าดีกว่า"
- ถ้าไม่มี audio device → ปิดฟีเจอร์นี้อย่างสง่างาม ส่วนวิเคราะห์ยังใช้ได้ปกติ

## Export
เลือกหลายไฟล์ในผลคัดกรอง → เลือกโฟลเดอร์ปลายทาง → copy ไป (จัดการชนชื่ออัตโนมัติ)

## Cache
เก็บผลวิเคราะห์ + curve ย่อ 96 จุด ลง `cache.json` (`%LOCALAPPDATA%/BestIR/`) เทียบจาก mtime+size — สแกนรอบหน้าไวขึ้นมาก (วิเคราะห์ไฟล์ใหม่เท่านั้น)

## หมายเหตุ
- UI เป็นภาษาอังกฤษ (ศัพท์ audio เช่น flat/bright/scooped เป็นมาตรฐานกลาง) — ถ้าอยากได้ UI ไทยบอกได้ครับ
- ฟีเจอร์พิเศษที่มาเกือบฟรีจากเครื่องจักรเดียวกัน (เลือก IR ที่ชอบเป็น "target" แล้วหาตัวใกล้เคียง) จะใส่เป็นปุ่ม "Use as Reference" ใน Inspector — ไม่เพิ่มขอบเขตงานมาก
- ไม่รวม dedup/CSV/favorites ตามที่คุณไม่ได้เลือก (ขยายทีหลังได้)
